# Snake Game

HTML Canvas üzerinde çalışan klasik yılan oyunu.

## Kurulum ve çalıştırma

`main.html` dosyasını modern bir masaüstü tarayıcısında açın.

## Kullanım

Ok tuşlarıyla yön değiştirin. Her yem skoru bir artırır. Duvara veya yılanın gövdesine çarptığınızda oyun biter. **Restart** ile yeni oyun başlatın.

## Proje yapısı

- `main.html` — oyun alanı, skor ve yeniden başlatma düğmesi.
- `app.js` — oyun döngüsü, yön, yem ve çarpışma.
- `style.css` — arayüz.
